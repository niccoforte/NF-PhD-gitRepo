# p2 Task Handoffs

This directory owns non-executable continuation briefs. Start with `HANDOFFS.md`
only to choose a task, then read that brief and applicable repository instructions.
Do not load unrelated briefs or treat historical proposals as outstanding commands.
Reconcile the user's latest decisions, current code and `../PROJECT_STATUS.md`
before acting; a brief alone does not authorise submission, bulk processing or cleanup.

Keep notebooks in `../code/`, HPC entry points in `../HPC/`, and human worked
examples in `../samples/`. Links within this directory are relative to the brief;
scientific source shorthand retains its explicitly stated repository/p2 scope.
When relocating a brief, update its index, incoming references and relative links.
Do not create duplicate copies or automatically message another chat.
